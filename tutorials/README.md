# Tutorials

Tutorials for building and customizing QUAM configurations. Both notebooks build QUA programs in memory and **run without QM hardware**.

- **[Voltage sequence lab](voltage_sequence.ipynb)** — Sticky `VoltageGate`, named point, `step_to_point`, and `keep_levels`. Then the [full DC / virtualization guide](../quam_builder/architecture/quantum_dots/voltage_sequence/README.md).
- **[Macro customization](macro_customization.ipynb)** — Use defaults, type-level override, instance-level override, and an external macro package.
